**`GSD.runParallel(<phase...>)` + the `/gsd-execute-parallel` command — parallel multi-phase execution (ADR 0014, Chunk C).** N independent backlog phases run concurrently in conflict-graph-scheduled waves (parallel within a wave, sequential across), each through its own research→plan→execute→verify lifecycle in an isolated worktree, promoting as its own auto-merged PR. Chunk C completes the ADR: a single global agent budget bounds total leaf (plan) dispatch across every concurrent phase, with a `parallelization.max_concurrent_phases` sub-cap bounding concurrent phases (D5), preventing oversubscription; new `parallelization.phase_level` gates the feature (with `git.sdk_worktree_execution` + Claude runtime); and the multi-wave PR-promote path now syncs local protected to origin (fetch + fast-forward) at each wave boundary so wave N+1 bases off wave N's promoted output. Builds on the ADR 0013 worktree/checkpoint/rollback engine reused across the wave loop: per-phase base SHA captured at wave start (D3), the orchestrator as the sole writer of `ROADMAP.md`/`STATE.md` across a wave (D2), and failure isolation that continues independents and skips only the failed phase's `depends_on` closure, including transitive dependents (D4).
