**Autonomous cross-phase execution + rollback protocol (ADR 0013 option 4).** `GSD.run` now drives an autonomous rollback + informed-retry loop that resolves the cross-phase state-rollback hazard D5 deferred. Each phase promotes onto the protected branch behind a per-phase checkpoint — an annotated `gsd/phase-N-base` tag plus a byte-snapshot of `STATE.md`/`ROADMAP.md`/`REQUIREMENTS.md` under `.planning/.checkpoints/phase-N/` — and an append-only promotion manifest `.planning/.phase-manifest.json` recording each phase's `base_sha..head_sha` commit range and phase-level `depends_on` edges. A GENUINE failure triggers a clean **Tier-1** rollback of the never-promoted phase (integration branch + base tag torn down, per-plan worktree branches force-deleted not merged, planning docs restored from the snapshot, fail-closed assert that protected is still LAST_GOOD) and an informed retry that injects the accumulated prior-failure context, up to `git.sdk_max_phase_attempts` (default 5), then HALTs for a human; a transient/quota failure resumes the SAME phase via WAITING.json without consuming an attempt. When the failure is file-**attributable** to an already-promoted predecessor in the failing phase's transitive `depends_on` closure, a **Tier-2** history-preserving `git revert` unwinds that predecessor (revert commit on protected behind the guard suite, summary/verification artifacts MOVED to `.planning/.rollback-quarantine/`, ROADMAP + REQUIREMENTS marked incomplete, STATE restored from the phase checkpoint) and then HALTs — reverting promoted work unattended is itself halt-worthy. A tristate classifier (`revert-confident` / `no-cascade-confident` / `cannot-classify`) enforces ATTRIBUTABLE-ONLY-else-HALT: any inability to decide (corrupt manifest, cyclic graph, unattributable failure) HALTs with a clean tree rather than guessing. The autonomous Tier-2 cascade is **capped at a single attributable predecessor** — two or more is `cannot-classify` (human review), since a multi-predecessor unwind would revert phase M, leave its uncommitted ROADMAP/REQ/STATE mutations, and make phase M-1's revert hit a dirty tree. A per-step crash-resume journal in `.planning/ROLLBACK.json` records each Tier-2 step's completion flag immediately, so a crash mid-unwind replays ONLY the remaining steps idempotently on the next `GSD.run` startup (the GIT step is skipped when already committed — no double-revert) and a second resume is a no-op. New git config keys: `git.sdk_max_phase_attempts` (default 5). All additions are additive and default-off-compatible; the existing phase-runner invariant suite stays green. See `docs/adr/0013-dynamic-workflow-parallelization.md` D5 (RESOLVED).
