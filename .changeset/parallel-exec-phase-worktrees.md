**Per-phase worktree isolation + failure-path isolation for the parallel wave executor (Chunk C PR-1 of ADR 0014, issue #13 gap 2).** Each wave member of `GSD.runParallel` now executes its isolated segment (checkpoint → integration branch → plan execution → verify) in its OWN linked git worktree, off the wave's protected base SHA, so two concurrent phases in a wave never race the shared `projectDir` working tree / index / `HEAD`. The promote-to-protected segment stays a serialized shared-`projectDir` operation (the protected branch can only be checked out in one worktree): under `openPullRequests:true` promotion is the per-phase PR admin-merge (D6); under `openPullRequests:false` it is the local serialized `GitPhaseIntegrationManager.promote()` under the `promoteMutex`.

The **FAILURE** segment is now isolated too (Design B, ADR 0014 D4 — fixes four concurrency defects in the earlier draft). On the parallel/deferred-promotion path a wave member that fails NEVER advanced protected, so it discards only its OWN integration branch (`git branch -D`, a refs-only mutation that cannot collide on `.git/index.lock`) instead of running the shared-`projectDir` Tier-1 (`git checkout protected` / restore `.planning` docs / assert `protected === LAST_GOOD`) or Tier-2 cascade. This removes: a concurrent-`index.lock` collision with a sibling's promote; a false-positive "non-green phase appears to have moved protected" fail-closed HALT once a sibling legitimately advanced protected; a shared-`ROLLBACK.json` clobber that corrupted the Tier-2 crash-resume journal (the parallel failure ledger now writes to a per-phase `.planning/.checkpoints/phase-<N>/ROLLBACK.json`); and an unserialized cascade-revert that could half-revert protected. Per-phase worktree add/remove ops are serialized under an instance mutex with a single retry on the `commondir` admin-file race, so high fan-out no longer spuriously fails a phase. Across-wave / already-promoted cascades stay the orchestrator's sequential job at wave boundaries.

The sequential `GSD.run` path is byte-equivalent (a phase's worktree dir is threaded only when present; absent → the original shared-`projectDir` Tier-1/Tier-2 path runs unchanged). Worktrees are removed after each phase settles (success/fail/skip). The `/gsd-execute-parallel` command, config, and the `onWaveStart` origin-sync for the multi-wave PR-promote path land in Chunk C PR-2.
